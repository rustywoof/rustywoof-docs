## Tabs

Tabs are useful for showing OS-specific or package-manager-specific commands.

<Tabs items={["Linux", "macOS", "Windows"]}>
  <Tab value="Linux">
    ```bash
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustywoof.dev | sh
    ```
  </Tab>
  <Tab value="macOS">
    ```bash
    curl --proto '=https' --tlsv1.2 -sSf https://sh.rustywoof.dev | sh
    ```
  </Tab>
  <Tab value="Windows">
    ```powershell
    iwr -useb https://sh.rustywoof.dev/win | iex
    ```
  </Tab>
</Tabs>
